Two-Watch Field Sim

The real watch code (game logic and screen renderer, MicroPython 1.29) running in your browser against a simulated radio. Drag the watches around and both screens react as the firmware would. Mockups: Sheikah Finder watch UI.

  3. Watch the chart and the rings. As A gets closer the rings speed up and brighten; warmer shows as an up-arrow.
  4. Tap A's screen to scan, then walk the arrow. Next to B, press Bump watches.
